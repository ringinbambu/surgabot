# 🤝 Panduan Kontribusi (Contributing Guidelines)

Terima kasih atas minat Anda untuk berkontribusi pada proyek **Surga Bot**!

## 📌 Cara Berkontribusi
1. **Fork** repositori ini ke akun GitHub Anda.
2. Buat branch baru untuk fitur atau perbaikan Anda:
   ```bash
   git checkout -b feat/nama-fitur
   ```
3. Lakukan commit dengan pesan yang jelas dan deskriptif.
4. Buka **Pull Request (PR)** dengan menjelaskan perubahan yang Anda buat.

## 💡 Standar Kode
- Kode MQL5 dan Python harus terstruktur rapi dan memiliki komentar penjelas.
- Pastikan tidak ada credential/kunci API rahasia yang di-commit.
